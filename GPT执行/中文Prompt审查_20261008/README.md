# Prompt 历史对照参考

本目录保留中文 Prompt 审查、中英文对照和整理快照，供理解规则来源与定位问题使用。

**当前有效 Prompt 在 `karma/agents/` 的 agent 文件中。** 本目录不是运行输入，也不是尚待逐条执行的任务清单。特别是 `中文Prompt逐步替换稿.md` 中“尚未应用”、旧行号及替换步骤是当时状态，不能据此对当前文件重新整体替换。

实体和关系 Prompt 目前分别集中在对应 agent 内；`extraction_support.py` 只负责解析与清理。要修改第二部分，请按根目录 `同事上手说明.md` 固定基线，一次修改一个重点，再检查输出和评估。
