下一轮 Prompt 精简可保留的检查

  1. Replace 复核独立事实。 修正目的、条件和集合边界后，逐项检查原有正确关系是否仍有独立条目。用 doc0/S2 与 doc2/S10 分别验证保留与合并。
  2. Remove 核查完整等价。 一条独立关系被长字段覆盖时，核对删除是否损失目标输出。用 doc0/S4、doc4/S2–S3 验证。
  3. 文本对比将连接变化落实到具体事实。 检查省略连接是否改变主体、成立条件或动作范围。用 doc1/S5、S8 核对是否新增整句关系，用 doc2/S10 检查集合数量变化。
  4. 固定反馈输入做重复试验。 固定重建、差异和候选实体，保存 messages、raw_response、application。找到首次分叉的阶段，区分上游输入差异、回复差异和程序拒绝。
