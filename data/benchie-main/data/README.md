# BenchIE 原始数据

本目录收录 BenchIE 发布的英文、中文和德文句子、人工参考标注，以及论文实验使用的系统抽取结果。数据由 Kiril Gashteovski、Mingying Yu、Bhushan Kotnis、Carolin Lawrence、Mathias Niepert 和 Goran Glavaš 发布，采用 CC BY 4.0 许可。本目录中的数据文件保留上游内容。 [上游数据](https://github.com/gkiril/benchie/tree/main/data) · [BenchIE 论文](https://aclanthology.org/2022.acl-long.307/) · [CC BY 4.0 许可](https://creativecommons.org/licenses/by/4.0/)

KARMA 使用的中文输入、事实簇标注和转换记录见配套目录。官方评分器及其软件许可见 BenchIE 上游仓库。 [KARMA 中文数据](../11.13%20input/README.md) · [官方评分器](https://github.com/gkiril/benchie/tree/main/src) · [软件许可](https://github.com/gkiril/benchie/blob/main/LICENSE.txt)
